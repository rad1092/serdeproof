# SerdeProof

Work only in this independent repository. Java 17 is the minimum. Keep the adapter API free of serializer dependencies. Never put payloads, raw errors, fixture filenames or dynamic JSON keys into default public reports. Run the relevant tests and `mvn verify` before release. CI and network access are authorized by the task; never spend money, acquire credentials, or widen account permissions.

Use Maven Central and official upstream releases. Do not claim semantic equivalence, sandboxing, signature, notarization, or cross-platform success without direct evidence. Preserve small tests and fixtures; keep generated bulk out of git.
